### 🌱 我的興趣｜Interests

我對醫療資訊、AI 與永續醫療充滿興趣，希望透過技術讓照護更貼近生活，也讓第一線醫護的工作更輕鬆。

- 🏡 **偏鄉與在宅醫療**：探索 FHIR、SMART on FHIR 與生成式 AI 的應用，串接跨機構照護資料，協助訪視紀錄整理與遠距決策支援。
- ⌚ **高齡健康與智慧監測**：關注穿戴裝置、數位生物標記、跌倒風險與運動復健，結合直覺易用的介面，支持日常健康管理。
- 🩺 **臨床流程與系統優化**：關心醫護的使用體驗，期待透過自動化與系統整合，減少重複輸入、操作負擔與資訊落差。
- 🌍 **ESG 與永續醫療**：探索無紙化、醫療資源效率、照護公平與健康資料治理，思考如何讓數位轉型兼顧環境、社會與治理。

> 💡 我相信，好的醫療科技應該服務使用者，讓照護更有溫度。
